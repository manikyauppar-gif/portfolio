Audio Forensic App to Detect Forgery

  • Python
  • Flask
  • PyTorch
  • Wav2Vec 2.0
  • Scikit-Learn
  • Librosa
  • React.js
  • Tailwind CSS
  • MongoDB Atlas
95.6%reported test accuracy of the final model, on the 15% held-out test split (overall accuracy). Per-class precision, recall and F1 are not yet reported.

Problem

Synthetic voices are now hard to tell from real ones, which creates risks of fraud, identity theft and misinformation. The app gives a moderator or an everyday user a quick real-versus-synthetic check.

My contribution

I built the backend and handled the deployment.

Key features

  • Upload a file or record from the browser microphone
  • Flask REST API (POST /api/analyze) serving PyTorch and scikit-learn inference
  • Frozen, pre-trained facebook/wav2vec2-base embeddings feeding a balanced Random Forest (100 trees)
  • Privacy by design: the audio file is deleted after analysis, only metadata is stored
  • Dashboard with scan history and CSV export
  • Trained on public Kaggle datasets plus codec-augmented and browser-recorded samples

How it works

  1. Upload or record (WAV, MP3, WebM, OGG)
  2. Mono, 16 kHz, silence trimmed, first 4 s
  3. Wav2Vec 2.0 embedding (768 values)
  4. Scaler + Random Forest
  5. Verdict + certainty %

Model development

Earlier experiments included MFCC with Random Forest and Wav2Vec 2.0 with Logistic Regression or an MLP. They used different corpora and test splits, so the scores are not directly comparable.

Real-world use

Screening voice messages and recordings for synthetic speech before they are trusted.

Known limitation: audio recorded in the browser is less reliable than clean uploads.

Problem
